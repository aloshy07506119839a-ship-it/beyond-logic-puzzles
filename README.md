# Beyond Logic Puzzles

أنشئ موقع لعبة متكاملًا باللغة العربية باسم «ما وراء المنطق».

أريد لعبة ألغاز غريبة وغامضة بتصميم احترافي داكن، وألوان بنفسجية، وواجهة RTL متوافقة مع الهواتف والكمبيوتر.

المتطلبات:

شاشة رئيسية جذابة وزر بدء اللعب.

30 لغزًا متنوعًا على الأقل، مع إجابات صحيحة وخاطئة وتلميحات.

مراحل تزداد صعوبة تدريجيًا.

نظام نقاط وإنجازات وحفظ تلقائي للتقدم.

شاشة نتائج وإمكانية استئناف اللعب وإعادة اللعب.

مؤثرات صوتية اختيارية وإعدادات للتحكم بها.

تصميم متجاوب وتجربة استخدام ممتازة على الهاتف.

إمكانية تثبيت الموقع كتطبيق ويب PWA.

تنظيم الملفات وتجهيز المشروع للنشر على الإنترنت.

اختبر وظائف اللعبة وأصلح الأخطاء قبل النشر.

ابدأ ببناء اللعبة فعليًا داخل المشروع، ولا تكتفِ بإنشاء تصميم ثابت.
